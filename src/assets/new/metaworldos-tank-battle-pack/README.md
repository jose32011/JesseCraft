# MetaWorldOS Tank Battle 3D Asset Pack v1.0.0
21 game-ready 3D models, packaged for anyone who needs a
starter kit without account signup or a paywall.
## Format
- **GLB (glTF 2.0 binary)** with Draco geometry compression
- **Y-up, +Z forward**, 1 unit = 1 meter (Unity / Godot convention)
- **Single mesh per file**, transforms applied
- PBR materials embedded where relevant
## Verified engines
- Unity 2022.3 LTS (built-in glTFast)
- Unreal Engine 5.4 (Interchange framework)
- Godot 4.3 (native GLB import)
- Three.js 0.170+ (GLTFLoader + DRACOLoader)
- Blender 4.2 (File → Import → glTF 2.0)
